# Go Developers Guide

A runnable full-stack reference app that IS the guide: a Go server (standard
library `net/http`) carries all of the teaching as a typed content API —
topics, sections, code blocks, and live demos — and a React client is a
presentation-only shell that renders it and never teaches React itself. The
whole stack runs on Docker (devcontainer + compose) so every snippet, demo,
and terminal tour in the guide is verified against the exact code in this
repository.

**Status:** In development — Phase 0.
